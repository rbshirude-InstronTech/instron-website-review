# Instron Technologies — Compact Website Review

The complete 32-page review website is embedded in one index.html file, including its images, styles and scripts. Publish this repository root with GitHub Pages; no build step is required. JavaScript must be enabled for page navigation.

The contact page prepares an email draft or copies enquiry text locally. It has no form backend, automatic email sending, CRM integration, analytics or visitor-data storage.

This compact deployment contains the website review only. Management records, approval files, source archives and Apps Script source are maintained separately.
